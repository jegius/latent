# Latent за одну страницу

Практическая сводка языка. Каждый блок кода проверен компилятором движка №2
(`web-ide/compiler.wasm`), если не помечено иное. Детали — по ссылкам.

## Каркас программы

```latent
fn main() -> int {
    print("hello");
    return 0;
}
```

- Точка входа — `fn main` (без неё модуль компилируется, но экспорта `main` нет).
- `;` обязательна после `let`, `return`, вызовов-инструкций; у `if`/`while`/
  `for`/`class`/`fn` — не нужна.
- Верхний уровень: `fn`, `class`, `enum`, `let`, `test`, `@декоратор`. Только
  `fn`/`class`/`enum` реально компилируются в код; top-level `let` и
  инструкции типизируются, но не исполняются.
- Комментарии: `//` и `/* ... */` (вложенные).

## Литералы и типы

```latent
fn main() -> int {
    let i = 42;             // int
    let f = 2.5;            // float
    let b = true;           // bool
    let s = "latent";       // string (UTF-8, [len][bytes])
    let n = null;           // null (нулевой указатель)
    let a = [1, 2, 3];      // [int]
    let m = [[1, 2], [3, 4]];
    let fnv = fn(x) => x * 2;
    return i;
}
```

- Строки: только `"..."`; escapes **только** `\n`, `\t`, `\\`, `\"`.
- Числа: десятичные, с `e`-экспонентой; `2.0` кодоген считает int.
- **Осторожно с `float`**: валидно только если и переменная, и все операнды
  синтаксически «дробные» (ненулевая дробная часть). `let x: float = 2;`,
  `fn f() -> float { return 5.0; }`, `1 + 2.5`, `[1.5, 2.5]`,
  `print(sqrt(16))` — компилируются, но WASM невалиден (см.
  [ограничения](../reference/errors.md#известные-ограничения-движка-2-компилируется-но-невалидный-wasm)).
- Аннотации: `let x: int = 1;`, `fn f(a: int) -> int`, `[float]`,
  `fn(int) -> int`, `channel`, `Name<A, B>`.
- `unit`/`void` — синонимы «нет значения».
- Union-типов и tuple-типов в синтаксисе **нет**.
- Проверка типов — HM-подобная, но операнды арифметики/сравнений и поля
  объектов почти не проверяются (см. [типы](./types.md)).

## Операторы (по убыванию приоритета)

```text
() [] .                  вызов, индекс, поле/метод
- ! <- await             унарные (префикс)
* / %                   90
+ -                     80
<< >>                   70
&                       60
| ^                     50
< > <= >=               40
== !=                   30
&&                      20
||                      10
=  <-                   2 (правая ассоциативность)
-> =>                   аннотация / лямбда (не вычисляются)
```

Особенности: `&&`/`||` — короткое замыкание; `==` для строк — по содержимому, для
массивов — по указателю (движок №2) или глубоко (движок №1); `+` со строкой —
конкатенация; `/` для int — целочисленное; побитовые операции есть только в
движке №2; `await` в движке №2 — прозрачно; `<-` — только host (каналы).
Подробно — [операторы](./operators.md).

## Управление

```latent
fn classify(n: int) -> string {
    if (n < 0) {
        return "negative";
    } else if (n == 0) {
        return "zero";
    } else {
        return "positive";
    }
}

fn main() -> int {
    let sum = 0;
    for (let i = 0; i < 5; i = i + 1) {
        sum = sum + i;
    }
    while (sum > 10) {
        sum = sum - 1;
    }
    for (let x in [1, 2, 3]) {
        sum = sum + x;
    }
    return sum;
}
```

- Условия — обязательно в `(` `)`.
- Две формы `for`: C-стиль и `for (let x in array)`; `for-in` по строке
  **не типизируется** (нужен массив) и не работает в №2.
- `break`/`continue` отсутствуют.
- `for (; cond; )` допустим (пустые части).

## Функции и лямбды

```latent
fn add(a: int, b: int) -> int { return a + b; }

fn main() -> int {
    let double = fn(x) => x * 2;
    let block = fn(x) { return x + 1; };
    let id = fn(x) => x;
    print(add(double(2), block(3)));
    return id(0);
}
```

- Параметры — через запятую, с необязательной аннотацией; возврат — `-> T`.
- Функции хойстятся: вызов до объявления работает.
- Лямбды: `fn(x) => expr` (выражение) или `fn(x) { ... }` (блок), замыкаются по
  значению; в №2 реализованы через `call_indirect`.
- Рекурсия поддержана; функцию без аннотации можно вызывать рекурсивно.
- Композиция/функции высшего порядка — обычные значения типа `fn(...) -> R`.

## Массивы и строки

```latent
fn main() -> int {
    let a = [1, 2, 3];
    a.push(4);
    let last = a.pop();
    print(len(a));        // 3
    print(a.length);      // 3
    print("hello".length); // 5 (байты)
    print("hello"[0]);    // 104 (байт 'h')
    return last;
}
```

- `len(x)`, `arr.push(v)`, `arr.pop()`, `.length`/`.length()`.
- Индексация без проверки границ; `s[i]` — байт.
- `push`/`pop`/индексация мутируют массив.
- Функциональной `pop` нет; функциональный `push(arr, v)` есть.
- Строки неизменяемы; `+` создаёт новую строку.

## Классы

```latent
class Counter {
    n: int;

    fn init() { this.n = 0; }

    fn inc() -> int {
        this.n = this.n + 1;
        return this.n;
    }
}

fn main() -> int {
    let c = new Counter();
    c.inc();
    return c.inc();
}
```

- Поля: `name: type;`, методы: `fn name(...)`, неявный `this`.
- Конструктор — метод `init`; поля инициализируются нулями (не `null`).
- Метод вызывается на переменной с известным классом (`this`, параметр-класс,
  локальная из `new Class`) — иначе кодоген №2 не найдёт метод.
- Наследования нет.

## Enum и match

```latent
enum Shape {
    Circle,
    Rect,
}

fn describe(s) -> int {
    return match s {
        case Circle: 1,
        case Rect: 2,
        default: 0,
    };
}

fn main() -> int {
    return describe(Circle);
}
```

- Варианты: `Name` или `Name(T, ...)`; встроенные `Ok/Err/Some/None`.
- `match` — выражение; `case` необязателен; `default`/`_` — wildcard.
- Паттерны: литералы, `_`, идентификатор-связка, конструктор варианта.
- Если ни одна ветка не совпала, движок №2 оставляет на стеке `0`, движок №1
  бросает ошибку.

## Тесты и контракты

```latent
test "arithmetic" {
    assert(1 + 1 == 2);
    assert_eq(2 * 3, 6);
}

fn main() -> int {
    return 0;
}
```

- `test "name" { ... }` исполняется движком №1 после `main`; результат не
  выводится в UI IDE (доступен через API интерпретатора).
- `assert(cond)` / `assert_eq(a, b)` — в движке №2 компилируются в trap при
  провале; второй аргумент-сообщение игнорируется; `assert_eq` сравнивает числа
  как i32, строки — по содержимому, массивы — по указателям.
- `@forall("...")`, `snapshot(...)`, `ai_contract(...)`, `enforce_contract(...)`
  — host-only движка №1; в №2 ошибка компиляции.
- Декораторы `@...` над `fn`/`class`: цель **не регистрируется** в таблице
  функций/классов — вызвать декорированную функцию/создать класс не получится
  (`Unknown function`). Над инструкциями декоратор прозрачен.

## Конкурентность (host-only в №2)

```text
channel<T>() / channel()   канал CSP (только движок №1)
spawn { ... } / spawn f()  горутина (в №2 — последовательно)
ch <- v / <-ch             send/recv (в №2 — ошибка компиляции)
select { case v <- ch: {...} default: {...} }   (в №2 — тело первой ветки)
yield;                     уступить планировщику (в №2 — no-op)
async fn / await           Promise; в №2 await прозрачен
```

- Движок №1: кооперативный планировщик, каналы на массивах, `recv` активно
  уступает планировщику; возможны дедлоки (диагностируются).
- Движок №2: каналов нет вообще — компиляция падает с понятной ошибкой.

## AI-примитивы (host-only в №2)

```text
ai_infer(model, prompt) -> string       # №1: mock/гейтвей; включён только "Run with AI"
ai_embed(text) -> [float]               # 8-мерный mock по умолчанию
ai_stream(model, prompt) -> handle      # поток токенов
stream_next(handle) -> string|null      # следующий токен или null
ai_generate!("prompt")                  # парсится №2, но кодоген -> ошибка host
tensor/data, semantic, matmul, cosine_similarity, dot, magnitude, zeros, ones
snapshot/ai_contract/enforce_contract
```

- В движке №2 — ошибка «требует host-рантайма» (кроме `ai_generate!`, который
  парсится/типизируется, но тоже ошибка кодогена).
- `ai.load/ai.infer/ai.embed/ai.agent` — не реализованы ни в одном движке
  (парсер таких узлов не создаёт; см. [AI-рантайм](../specs/ai-runtime.md)).

## Ошибки и диагностика

- Кодов ошибок нет; формат: `... на строке L:C`.
- Лексер: `Неожиданный символ`, `Незавершённая строка`,
  `Неверная escape-последовательность`, `Неверный формат числа`,
  `Незавершённый блочный комментарий`.
- Парсер: `Ошибка парсинга на строке L:C: ожидалось '<...>', найдено <Токен>`,
  `Неожиданный конец файла...`.
- Тайпчекер: `Неопределённая переменная`, `Несовпадение типов`,
  `Несовпадение арности`, `Бесконечный тип`, `Не функция`.
- Кодоген: `Unknown function`, `Builtin '...' не поддерживается движком №2
  (требует host-рантайма)`, `Метод '...' ...`, `Unknown field/class`,
  `Undefined variable`.
- Полный каталог — [диагностики](./errors.md).

## Компиляция и запуск

```bash
latentc compile app.lat app.wasm     # CLI
latentc check app.lat                # полный проход без записи

node run.mjs app.wasm                # хост: env.print + memory + main
```

Минимальный хост — в [CLI](./cli.md); ABI модуля — в [WASM ABI](./wasm-abi.md);
сам компилятор как WASM — там же (C-ABI `latent_alloc/compile/free/version`).

## Движки: краткая таблица

| Фича | №2 (Rust→WASM) | №1 (JS) |
|---|---|---|
| `let`/`if`/`while`/`for`/`fn`/рекурсия | ✅ | ✅ |
| массивы, `push/pop/length`, `len` | ✅ | ✅ |
| строки, `+`, `==`, `s[i]`, `len` | ✅ | ✅ |
| классы/`new`/`this`/методы | ✅ (с ограничениями) | ✅ |
| enum/`match` | ✅ (кроме float-полей) | ❌ enum не поддержан |
| лямбды/замыкания | ✅ | ✅ |
| `async`/`await` | ✅ (await — passthrough) | ✅ |
| `channel`/`spawn`-каналы/`select`-ожидание/`yield` | ❌ host | ✅ |
| AI/тензоры/контракты/snapshot | ❌ host | ✅ (mock/гейтвей) |
| побитовые операторы | ✅ | ❌ (лексическая ошибка) |
| `str/int/float/sqrt` | ✅ | ❌ (нет таких builtins) |
| `enum` | ✅ | ❌ |
