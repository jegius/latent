# Матрица паритета

Три реализации языка в репозитории:

| Обозначение | Что это | Где |
|---|---|---|
| **Rust** (движок №2) | компилятор Latent → WASM | `src/`, `latentc`, `web-ide/compiler.wasm` |
| **selfhost** | компилятор Latent → WASM, написанный на Latent | `selfhost/src/*.lat`, `selfhost/shc.lat` |
| **JS** (движок №1) | tree-walking интерпретатор | `web-ide/compiler/` |

Как проверялось:

- **Rust**: каждое утверждение проверено компиляцией и запуском программ через
  поставляемый `web-ide/compiler.wasm` в Node (Node 24, `WebAssembly`).
- **JS**: программы запускались через `runLatent(src, withAI)` из
  `web-ide/compiler-loader.js`.
- **selfhost**: по `selfhost/README.md` и `selfhost/src/*.lat`; цепочка
  bootstrap в рамках подготовки этой страницы не перезапускалась (это делают
  `selfhost/test` и [tooling/bootstrap](../tooling/bootstrap.md)).

Легенда: ✅ работает; ⚠️ работает с ограничениями/дефектами; ❌ не
поддерживается; **host** — только при наличии host-рантайма (движок №1).

## Лексика

| Возможность | Rust | selfhost | JS |
|---|---|---|---|
| `//` комментарии | ✅ | ✅ | ✅ |
| `/* */` (вложенные в Rust) | ✅ (вложенные) | ✅ (без вложенности) | ❌ |
| десятичные числа | ✅ | ✅ | ✅ |
| экспонента `1e3` | ✅ | ❌ | ❌ |
| escapes `\n \t \\ \"` | ✅ (только они) | ⚠️ не обрабатываются | ✅ (любой `\X` → `X`) |
| мягкие ключевые слова как имена | ✅ (`test`, `model`, ...) | ⚠️ частично (свой набор) | ✅ (`test`, `tensor`, ...) |
| `->`, `=>`, `<-` | ✅ | ✅ (`->`, `=>`; `<-` нет) | ✅ |
| `::` | лексируется, не используется | ❌ | лексируется как два `:` |
| побитовые `& \| ^ << >>` | ✅ | ✅ | ❌ (лексическая ошибка) |
| `async`/`await` | ✅ | ❌ | ✅ |
| `spawn`/`select`/`yield`/`channel` | ✅ (синтаксис) | ❌ | ✅ |

## Известные дефекты Rust-кодогена (сводно)

Проверено на поставляемой сборке `web-ide/compiler.wasm`; подробнее —
[errors → известные ограничения движка №2](../reference/errors.md#известные-ограничения-движка-2-компилируется-но-невалидный-wasm):

- `let x: float = 2;`, `fn f() -> float { return 5.0; }` — невалидный WASM;
- `1 + 2.5`, `1 < 1.5`, `5.5 % 2.0` — невалидный WASM;
- `print(sqrt(16))`/`int(sqrt(16))` — невалидный WASM (в f64-контексте
  `-> float { return sqrt(16); }` валиден);
- массивы с float, float-поля классов/параметры/захваты, float-payload enum;
- `match` с void-ветками, `fn f() -> unit { return; }`, `let x = print("a");`;
- `new Class(...)` без `init` в достижимом коде;
- `print` строк из `.to_str()` иногда печатает указатель;
- поставляемый `compiler.wasm` **старше** `src/`: нет `alloc/load8/store8/load32/store32/memcopy`.

При этом **selfhost — строгое надмножество эталона по float**: по
`selfhost/README.md`, случаи `int(2.5 * 4.0)`, `int(sqrt(16.0))`,
`let x: float = 2.5`, `str(2.5)`, `2 < 2.5`, `1 + 0.5` дают в selfhost валидный
WASM и верный результат, тогда как `latentc` на них падает с невалидным WASM.
Это расхождение зафиксировано честно: «эталон» не всегда эталон по float.

## Расхождения документации с кодом

Зафиксированы при подготовке справочника (важно для тех, кто опирается на
старые описания):

| Источник | Утверждение | Фактически |
|---|---|---|
| `web-ide/README.md` | «движок №1 реализует все конструкции языка» | нет `enum`, побитовых операторов, `str/int/float/sqrt`, блочных комментариев, `Name<...>` |
| `web-ide/README.md` | движок №2 поддерживает `ttest/assert_eq` | `test`-блоки компилируются, но не исполняются; исполняются только `assert`/`assert_eq` |
| `tooling/language-data/language.json` | `str/int/float/sqrt` — `engine: both` | только движок №2 |
| `tooling/language-data/language.json` | `ai.load/ai.infer/ai.embed/ai.agent` — синтаксис | парсер таких узлов не создаёт (только `ai_infer`-функции и `ai_generate!`) |
| `tooling/language-data/language.json` | `& \| ^ << >>` — `engine: both` | в движке №1 лексер падает на `& \| ^` |
| `PLAN.md` | `compiler.wasm` актуален на коммите | сборка не содержит memory-builtins из текущего `src/` |
| `src/types.rs` | `LatentType`/`AIType`/`ConcurrencyType` | компилятор использует `typechecker::Type`; дублирующая модель |
| `selfhost/README.md` | Rust-компилятор «эталон» | эталон местами сам выдаёт невалидный WASM (float) — selfhost строже |
