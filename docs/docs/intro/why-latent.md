# Зачем нужен Latent

Latent — экспериментальный язык, который проверяет три гипотезы:

1. **AI-примитивы должны быть частью языка, а не SDK.** Если инференс,
   эмбеддинги и тензоры — обычные конструкции грамматики, программы проще
   читать, а инструменты (IDE, MCP, линтеры) могут понимать их статически.
2. **Компилятор в WASM может быть компактным и понятным.** Latent не
   использует LLVM: у него собственный кодогенератор WASM (`src/codegen/`),
   который умеет ровно то, что нужно языку, — и это позволяет держать весь
   компилятор в одном репозитории и даже переписать его на самом языке
   (`selfhost/`).
3. **Тесты, контракты и самоисправление — не надстройка, а часть процесса.**
   `test`-блоки, `assert`, `snapshot`, `@forall` и `@ai_contract` — это
   синтаксис, а не библиотеки.

## Что получается на практике

- **Один исходник — два рантайма.** Файл `.lat` можно выполнить
  интерпретатором (движок №1: большая часть языка + host-фичи, но без `enum`,
  битовых операторов и блочных комментариев) и скомпилировать в WASM-модуль
  (движок №2: «чистое» подмножество языка).
- **Понятный ABI.** Скомпилированный модуль экспортирует `main` и память,
  импортирует одну host-функцию `env.print`. Этого достаточно, чтобы запускать
  программы в браузере, в Node.js и в любом WASM-хосте.
- **Маленький, но самодостаточный язык.** Классы, enum + pattern matching,
  лямбды и замыкания, массивы/строки, `async`/`await`, CSP-конкурентность,
  низкоуровневые примитивы памяти.

## Latent в вебе

Latent компилируется в компактный WASM-модуль с одним импортом (`env.print`) и
двумя экспортами (`memory`, `main`), поэтому его можно встроить в браузерную
страницу без бандлера: `fetch` → `WebAssembly.instantiate` → вызов `main()`.
Это делает язык практичным для фронтенда: вычисления, парсинг, обработка данных
и игровая логика выполняются в WASM рядом с UI, а не на сервере.

Playground — полноценная браузерная IDE: host-фичи (каналы, `spawn`/`select`,
AI-примитивы, тензоры, контракты) исполняются движком №1 с авто-фолбэком, а
ленивая загрузка и чанки (`engine2` / `ai` / `editor` / `examples` / `core`)
уменьшают стартовый бандл. Начните с
[Latent в браузере за 5 минут](../getting-started/web-browser.md) и
[Latent во фронтенде](../guide/web-and-frontend.md).

## Кому это интересно

- **Исследователям языков и компиляторов** — как устроен маленький, но полный
  тулчейн: лексер → парсер → Hindley–Milner-подобная типизация → WASM.
- **AI-агентам и их разработчикам** — у языка машинно-читаемая документация:
  `llms.txt`, MCP-сервер документации, проверка кода через `compiler.wasm`.
- **Тем, кто учится писать компиляторы** — весь код на Rust и на самом Latent
  открыт, а self-hosted компилятор служит живым примером.

## Чего Latent сознательно не делает

Честность важнее маркетинга — вот чего в языке **нет**:

- нет модулей, пакетов и импортов: программа — один файл;
- нет наследования и интерфейсов: классы — это поля, методы и конструктор
  `init`;
- нет пользовательских обобщённых типов: `Name<T>` разбирается парсером и
  используется для встроенных типов, но собственные generic-классы не
  поддерживаются;
- нет `break`/`continue`, `switch`, тернарного оператора, строковой интерполяции
  и исключений;
- нет сборки мусора: память в WASM — bump-аллокатор, освобождения нет;
- нет полноценной стандартной библиотеки: встроенные функции перечислены в
  [руководстве](../guide/functions.md) и справочнике;
- движок №2 поддерживает подмножество языка и в нём host-фичи (каналы, AI,
  тензоры) дают ошибку `«требует host-рантайма»`; для пользователя эта граница
  прозрачна — playground исполняет их движком №1 с авто-фолбэком
  ([web IDE](../tooling/web-ide.md)).

Это не список недостатков на будущее, а **зафиксированный объём** языка:
проект исследует, насколько далеко можно уйти с таким ядром.

## Первый взгляд на код

```latent
fn triple(x: int) -> int {
    return x * 3;
}

fn main() -> int {
    let values = [3, 1, 4, 1, 5];
    let total = 0;
    for (let v in values) {
        total = total + triple(v);
    }
    print("triple sum:", total);
    return total;
}
```
