# Latent

**Latent** — небольшой статически типизированный язык, который компилируется в
**WebAssembly**. AI-примитивы для инференса, эмбеддингов и тензоров здесь входят
в грамматику, а тесты и контракты записываются обычными конструкциями языка —
без SDK и без макросов.

У Latent два движка, и с ними придётся иметь дело каждому, кто пишет больше пары
строк:

| Движок | Что это | Где живёт |
|---|---|---|
| **№1** | Tree-walking интерпретатор на JavaScript. Широкое подмножество языка плюс host-фичи: каналы, горутины, AI-примитивы, самоисправление. Не поддерживает `enum`, битовые операторы и блочные комментарии. | `web-ide/compiler/` |
| **№2** | Компилятор на Rust, собранный в WASM (`web-ide/compiler.wasm`). Превращает подмножество языка в WASM-модуль. | `src/`, `web-ide/compiler.wasm` |

В конце большинства тем руководства есть раздел «Ограничения движка №2»;
сводная таблица различий — в
[wasm-and-execution](./guide/wasm-and-execution.md#различия-движков). Полный
список известных ограничений и план их снятия — в [реестре](./specs/limitations.md)
и [дорожной карте](./specs/roadmap.md).

## Что уже работает

- **Статическая типизация с выводом типов.** Аннотации типов необязательны:
  `let x = 42;` выводит тип из значения. Работают `int`, `float`, `bool`,
  `string`, массивы `[T]`, функции `fn(T) -> R`, каналы и пользовательские
  типы (классы, enum).
- **Компиляция в WASM.** Исходник `.lat` превращается в бинарный модуль
  WebAssembly с экспортом `main` и импортом `env.print(i32)`. Тот же код
  исполняется в браузере (web IDE) и в Node.js, а сам модуль можно встроить в
  страницу как вычислительное ядро — см.
  [Latent во фронтенде](./guide/web-and-frontend.md).
- **Функции первого класса.** Лямбды `fn(x) => x * 2` и блочные лямбды
  `fn(x) { ... }`, замыкания, функции высшего порядка, взаимная рекурсия.
- **Классы и enum.** Поля, методы, `this`, конструктор `init`; sum-типы
  `enum` и pattern matching `match`/`case`/`default`.
- **Массивы и строки.** Литералы, индексация, `length`, `push`/`pop`, `len`,
  конкатенация; сравнение строк по содержимому работает в движке №1, в №2 это
  пока известный дефект.
- **Файловые модули.** `import { a, b as c } from "./x.lat"`, `export fn/class/enum`,
  двухфазная линковка и `latentc compile/check/bundle`. Пакетов и менеджера
  зависимостей нет.
- **Конкурентность в стиле CSP.** `spawn`, `channel`, `select`, `yield`,
  операторы `ch <- v` и `<-ch` (движок №1).
- **AI-примитивы как синтаксис.** `ai_infer`, `ai_embed`, `ai_stream`,
  `tensor`, `semantic`, `matmul`, `cosine_similarity` (движок №1).
- **Тесты и контракты.** `test "name" { ... }`, `assert`, `assert_eq`,
  `snapshot`, декораторы `@forall` и `@ai_contract`.
- **Низкоуровневые примитивы.** `alloc`, `load8`, `store8`, `load32`,
  `store32`, `memcopy` — на них написан self-hosted компилятор в `selfhost/`.

## Быстрый пример

```latent
fn square(x: int) -> int {
    return x * x;
}

fn main() -> int {
    let numbers = [1, 2, 3, 4, 5];
    let total = 0;
    for (let n in numbers) {
        total = total + square(n);
    }
    print("sum of squares:", total);
    return total;
}
```

Программа выведет `sum of squares:` и `55` (в движке №1 — одной строкой
`sum of squares: 55`, в движке №2 — двумя строками: `print` вызывает
`env.print` для каждого аргумента) и вернёт `55`.

Запустите её в браузере: <PlaygroundLink>открыть playground</PlaygroundLink>.

<PlaygroundFrame height="520px" title="Latent playground — быстрый пример" />

Скомпилируйте её локально:

```bash
cargo build --bin latentc
./target/debug/latentc compile hello.lat hello.wasm
```

## Статус проекта

Latent — молодой язык: версия компилятора `0.1.0`, экосистема только
складывается. Файловые модули v1 уже есть, а вот пакетов, наследования классов,
пользовательских обобщённых типов, `break`/`continue` и сборки мусора нет. Это не
случайность и не «забыли»: часть ограничений — сознательный выбор, часть — работа,
которая ещё не сделана. Разделить одно и другое помогает
[реестр ограничений](./specs/limitations.md) с приоритетами и обходными путями.

Self-hosted компилятор на самом Latent дошёл до фиксированной точки
`stage2 === stage3`; паритетная матрица почти вся зелёная, но отдельные
расхождения движков ещё задокументированы и не все закрыты тестами. Rust для
повседневной работы не обязателен: bootstrap запускается из `selfhost/seed.wasm`
(`node selfhost/bootstrap-wasm.mjs`), а Rust нужен только для обновления seed.

Если вы AI-агент: начните с <a href="/latent/llms.txt">llms.txt</a>, а точные
сигнатуры встроенных функций ищите в `guide/` и `reference/`.
