# Глава 7. Enum и match

:::caution Движок №2

`enum` и pattern matching — это **движок №2** (Rust → WASM). JS-интерпретатор
(движок №1) не поддерживает `enum` (ошибка `Unexpected token '{'`), поэтому
запускать такие программы нужно через скомпилированный WASM-модуль
(см. [hello-world](../getting-started/hello-world.md)) или CLI-раннер. В
playground их можно **скомпилировать** (Engine #2), но не исполнить.

:::

## Объявление enum

```latent
enum Color { Red, Green, Blue }

fn name(c: Color) -> string {
    return match c {
        case Red(): "red",
        case Green(): "green",
        case Blue(): "blue",
        default: "unknown",
    };
}

fn main() -> int {
    print(name(Green));
    print(name(Blue));
    return 0;
}
```

Синтаксис:

```text
enum Имя { Вариант, Вариант(Тип, ...), Вариант }
```

- запятая между вариантами **обязательна**, завершающая допускается;
- вариант без полей — это тег (`i32`), а не указатель;
- вариант с полями — указатель на `[тег][поле0][поле1]...` в линейной памяти;
- теги присваиваются по порядку: `Red = 0`, `Green = 1`, `Blue = 2`.

## Варианты с данными

```latent
enum Shape { Circle(int), Rect(int, int), Empty }

fn area(s: Shape) -> int {
    return match s {
        // 0-арный вариант — по значению-тегу; он должен идти раньше
        // вариантов с полями (у тех тег читается по указателю).
        case Empty(): 0,
        case Circle(r): 3 * r * r,
        case Rect(w, h): w * h,
    };
}

fn main() -> int {
    print("circle:", area(Circle(10)));
    print("rect:", area(Rect(3, 4)));
    return area(Circle(10));
}
```

Обратите внимание на `case Empty():` — **со скобками**. Это конструктор с
нулём аргументов. Если написать `case Empty:` без скобок, парсер создаст
паттерн-связывание `Empty` (см. ниже), и такая ветка будет ловить всё подряд.

Есть и второе правило: **0-арные варианты должны идти в `match` раньше
вариантов с полями**. Для 0-арного варианта проверяется само значение-тег, а
для варианта с полями кодоген читает тег по указателю; если значение-тег
попадёт в ветку с полями, она прочитает память по маленькому адресу и может
ложно совпасть с тегом `0`.

## Match: правила

`match` — **выражение**, возвращающее значение:

```text
match scrutinee {
    case Паттерн: выражение,
    case Паттерн: выражение,
    default: выражение,
}
```

- ветки разделяются **запятыми**; последняя запятая необязательна;
- тело ветки — **выражение**, не блок (`{ ... }` не допускается);
- `case` можно опустить: `match n { 1: "one", default: "many" }`;
- `default` и `_` — wildcard; должны стоять последними;
- литеральные паттерны: числа и строки (bool-литералы **не** поддерживаются
  парсером: `case true:` даёт `ожидалось 'pattern', найдено Bool(true)`);
- паттерн-идентификатор (`case x:`) **связывает** значение с именем и
  срабатывает всегда — это «поймать всё с именем»;
- паттерн-конструктор (`case Circle(r):`) проверяет тег и связывает поля.

Пример со связыванием:

```latent
fn classify(n: int) -> string {
    return match n {
        case 0: "zero",
        case 1: "one",
        default: "many",
    };
}

fn abs_value(n: int) -> int {
    return match n {
        case x: x * 2, // связка: срабатывает всегда
    };
}

fn main() -> int {
    print(classify(0));
    print(classify(7));
    print(abs_value(-3));
    return 0;
}
```

## Result-подобные значения

В компилятор встроены конструкторы `Ok`/`Err` (и `Some`/`None`), доступные без
объявления:

```latent
fn from_result(r) -> int {
    return match r {
        case Ok(v): v,
        case Err(e): -1,
    };
}

fn main() -> int {
    print("ok:", from_result(Ok(42)));
    print("err:", from_result(Err("bad")));
    return from_result(Ok(7));
}
```

:::caution Option

`Some`/`None` имеют общий тег `0`, поэтому в движке №2 паттерны `Some`/`None`
семантически ненадёжны. Для переносимого кода используйте `Ok`/`Err`: у них
теги `0` и `1` и они различаются корректно.

:::

## Как это работает в памяти

| Значение | Представление |
|---|---|
| `Red` (0-арный вариант) | число-тег (например, `0`) |
| `Circle(10)` | указатель: `[tag=0][10]`, 8 байт |
| `Rect(3, 4)` | указатель: `[tag=1][3][4]`, 12 байт |
| `Ok(7)` | указатель: `[tag=0][7]` |
| `Err("bad")` | указатель: `[tag=1][ptr-to-string]` |

Поля хранятся по 4 байта, поэтому enum с `float`-полями в движке №2 даёт
невалидный WASM — используйте целочисленные поля (или `int(float(x))`).

## Ограничения движка №2

- `enum` — только движок №2; JS-интерпретатор его не знает.
- Паттерны-bool не поддерживаются парсером.
- Тела веток `match` — выражения; `return`/`print` внутри ветки как инструкция
  допустимы только если ветка целиком выражение, возвращающее значение
  (`match` с void-ветками даёт невалидный WASM).
- Вложенные конструкторы в паттернах не проверяются (связывание — только
  верхний уровень).
- Дубликаты вариантов и дубликаты `enum` не диагностируются.
