# Глава 3. Операторы и управление

## Арифметика

```latent
fn main() -> int {
    let a = 17;
    let b = 5;
    print("a + b =", a + b);
    print("a - b =", a - b);
    print("a * b =", a * b);
    print("a / b =", a / b);   // целочисленное деление: 3
    print("a % b =", a % b);   // остаток: 2
    print("2 + 3 * 4 =", 2 + 3 * 4);     // 14 — умножение выше
    print("(2 + 3) * 4 =", (2 + 3) * 4); // 20 — скобки
    return 0;
}
```

Деление — важное различие движков:

- **движок №2 (Rust → WASM)**: `17 / 5 == 3`, деление целых усекает к нулю,
  остаток — `i32.rem_s` (`7 % 3 == 1`);
- **движок №1 (JS)**: все числа — `float`, поэтому `17 / 5 == 3.4`.

Пишите переносимый код так, чтобы это различие не влияло на результат, либо
явно используйте `int(x)` для приведения. Полная таблица расхождений —
в [различиях движков](../guide/wasm-and-execution.md#различия-движков).

## Сравнения и логика

```latent
fn main() -> int {
    let a = 17;
    let b = 5;
    print("a == b:", a == b);
    print("a != b:", a != b);
    print("a > b:", a > b, " a < b:", a < b);
    print("a >= b:", a >= b, " a <= b:", a <= b);

    let t = true;
    let f = false;
    print("t && f:", t && f);
    print("t || f:", t || f);
    print("!t:", !t);
    return 0;
}
```

`&&` и `||` — с коротким замыканием: правая часть не вычисляется, если результат
уже известен. Это значит, что `false && (1 / 0 > 0)` не приведёт к делению на
ноль в движке №1 (в движке №2 выражение компилируется, но `1/0` в WASM —
trap, если до него дойдёт выполнение).

## Битовые операторы

```latent
fn main() -> int {
    print("1 << 4 =", 1 << 4);   // 16
    print("16 >> 2 =", 16 >> 2); // 4
    print("7 & 3 =", 7 & 3);     // 3
    print("1 | 2 =", 1 | 2);     // 3
    print("5 ^ 1 =", 5 ^ 1);     // 4
    return 0;
}
```

`>>` — арифметический сдвиг вправо (`i32.shr_s`), `<<` — логический влево.

## Полный список операторов

От самого «сильного» к самому «слабому» (как в Pratt-парсере):

| Приоритет | Операторы | Ассоциативность |
|---|---|---|
| 1 (постфикс) | `f(x)`, `a[i]`, `obj.field` | левая |
| 2 (префикс) | `-x`, `!x`, `await x`, `<-ch` | правая |
| 3 | `*`, `/`, `%` | левая |
| 4 | `+`, `-` | левая |
| 5 | `<<`, `>>` | левая |
| 6 | `&` | левая |
| 7 | `^`, `\|` | левая |
| 8 | `==`, `!=` | левая |
| 9 | `<`, `>`, `<=`, `>=` | левая |
| 10 | `&&` | левая |
| 11 | `\|\|` | левая |
| 12 | `ch <- v` | правая |
| 13 | `=` | правая |

## `if` / `else if` / `else`

Условие обязательно в скобках, тело — в фигурных:

```latent
fn classify(n: int) -> string {
    if (n < 0) {
        return "negative";
    } else if (n == 0) {
        return "zero";
    } else {
        return "positive";
    }
}

fn main() -> int {
    print(classify(-5));
    print(classify(0));
    print(classify(7));
    return 0;
}
```

**Условие обязано быть `bool`**. В движке №2 `if (1) { ... }` — ошибка
типизации (`Несовпадение типов ... ожидалось 'float', найдено 'bool'`), даже
несмотря на то, что в динамических языках `1` обычно истинно. Движок №1
принимает truthiness; для переносимого кода пишите `if (flag)` или
`if (x != 0)`.

## `while`

```latent
fn main() -> int {
    let n = 27;
    let steps = 0;
    while (n != 1) {
        if (n % 2 == 0) {
            n = n / 2;
        } else {
            n = 3 * n + 1;
        }
        steps = steps + 1;
    }
    print("collatz(27) steps:", steps);
    return steps;
}
```

Отдельных `break`/`continue` в языке нет: цикл завершается по условию.

## `for` в стиле C

```latent
fn main() -> int {
    let sum = 0;
    for (let i = 1; i <= 10; i = i + 1) {
        sum = sum + i;
    }
    print("sum 1..10:", sum);
    return sum;
}
```

Заголовок: `for (инициализация; условие; шаг)`. Любая из трёх частей может быть
пустой: `for (;;)` — вечный цикл (выход — через `return` из функции).

## `for-in` по массиву

```latent
fn main() -> int {
    let numbers = [1, 2, 3, 4];
    let total = 0;
    for (let n in numbers) {
        total = total + n;
    }
    print("total:", total);
    return total;
}
```

`for (let x in ...)` работает с массивами; итерация по строке — ошибка
типизации (движок №2). Индекс здесь недоступен; для него используйте `for` в
стиле C.

## Упражнение

Напишите FizzBuzz для чисел от 1 до 20: если число делится на 15 — печатайте
`FizzBuzz`, иначе на 3 — `Fizz`, иначе на 5 — `Buzz`, иначе само число.

```latent
fn main() -> int {
    for (let i = 1; i <= 20; i = i + 1) {
        if (i % 15 == 0) {
            print("FizzBuzz");
        } else if (i % 3 == 0) {
            print("Fizz");
        } else if (i % 5 == 0) {
            print("Buzz");
        } else {
            print(i);
        }
    }
    return 0;
}
```
