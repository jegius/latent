# Web IDE (playground)

Playground — браузерная IDE в стиле IntelliJ IDEA Darcula:
редактор с подсветкой, дерево файлов, примеры, консоль вывода и AI-режим.
Она живёт по адресу <PlaygroundLink>/latent/playground/</PlaygroundLink> и
собирается из `web-ide/`.

<PlaygroundFrame height="640px" title="Latent playground" />

## Как устроены движки в IDE

| Движок | Что делает в IDE | Где |
|---|---|---|
| **№1** | **Исполняет программу** (`Run`, `Run with AI`): tree-walking интерпретатор на JS. Поддерживает большую часть языка, включая каналы, goroutines, тензоры и AI-примитивы; **не** поддерживает `enum`, битовые операторы и блочные комментарии. | `web-ide/compiler/` |
| **№2** | **Компилирует** программу настоящим Rust-компилятором в байты WASM и показывает результат во вкладке WASM. Исполнение скомпилированного модуля в IDE не выполняется. | `web-ide/compiler.wasm` |

Важно: `Run` всегда запускает движок №1, даже если загружен движок №2.
Движок №2 — это компилятор: он проверяет программу и выдаёт WASM-байты
(`Compiled by engine #2 (Rust → WASM)`). Чтобы выполнить полученный модуль,
нужен внешний WASM-хост — например, Node.js
(см. [hello-world](./hello-world.md)).

Если `compiler.wasm` недоступен, движок №2 просто не загружается — IDE
продолжает работать на движке №1. Индикатор активного движка — в правой части
статус-бара.

## Что реально поддерживается

| Фича | №1 (JS, исполнение) | №2 (Rust → WASM, компиляция) |
|---|:---:|:---:|
| `let`, `if/else`, `while`, `for`, `for-in`, `return`, `print` | ✅ | ✅ |
| функции, рекурсия, лямбды, замыкания | ✅ | ✅ |
| массивы, индексация, `push`/`pop`/`length`, `len` | ✅ | ✅ (см. оговорки в guide) |
| `class`/`new`/`this` (поля, `init`, методы) | ✅ | ✅ (целочисленные поля) |
| `match`/`case`/`default` | ✅ | ✅ |
| `enum` | ❌ | ✅ |
| битовые операторы `& \| ^ << >>` | ❌ | ✅ |
| `async`/`await` | ✅ | ✅ (`await` — passthrough) |
| `channel`, `spawn`, `select`, `yield` | ✅ (полноценно) | `spawn`/`select`/`yield` — суррогаты; `channel` — ошибка |
| `tensor`, `semantic`, `matmul`, `cosine_similarity` | ✅ | ⚠️ ошибка host-рантайма |
| `ai_infer`, `ai_embed`, `ai_stream`, `ai_generate!` | ✅ (нужен AI-режим) | ⚠️ ошибка host-рантайма |
| `test`-блоки, `assert`, `assert_eq` | ✅ | `assert`/`assert_eq`; тест-блоки не исполняются |
| блочные комментарии `/* ... */` | ❌ | ✅ |

## Как запустить

1. Откройте <PlaygroundLink>playground</PlaygroundLink>.
2. Напишите программу или выберите пример: `File → Examples` либо папка
   `examples/` в дереве проекта.
3. **Run** (`Ctrl/⌘+Enter`) — исполнить движком №1.
4. **Run with AI** (`Ctrl/⌘+Shift+Enter`) — исполнение с self-repair до 3
   попыток и AI-инсайтами.
5. **Compile / Engine #2** — скомпилировать Rust-компилятором и посмотреть
   WASM-байты.

## Возможности IDE

- **Редактор**: canvas-рендер, номера строк, подсветка текущей строки,
  скролл, выделение; ввод через скрытый `textarea` (IME/кириллица/undo).
  Автоотступ на Enter, автозакрытие скобок/кавычек, Tab/Shift+Tab.
- **Форматирование**: `Edit → Format Code` (`Ctrl/⌘+Alt+L`) — выравнивание по
  фигурным скобкам и нормализация пробелов (строки и комментарии не
  трогаются); тот же алгоритм — `web-ide/services/formatter-service.js`.
- **Модальные окна**: собственный слой (`views/modal-view.js`) вместо
  браузерных `confirm`/`prompt`/`alert` — оверлей, анимация, фокус-ловушка,
  Enter/Escape.
- **Дерево файлов**: создание (`＋`), переименование, удаление `.lat`-файлов;
  всё персистится в `localStorage`.
- **Табы и статус-бар**: Ln/Col, активный движок, имя файла; средняя кнопка
  мыши по табу закрывает файл.
- **Примеры**: реальные `.lat`-файлы в `web-ide/examples/` (единый источник
  правды) — Language, Algorithms, Data, Functional, Concurrency, AI, Misc.
- **Share**: код кодируется в base64 прямо в URL — ссылкой можно поделиться.
- **auto-run**: дебаунсированный автозапуск при редактировании.
- **Горячие клавиши**: `Ctrl/⌘+Enter` — Run, `Ctrl/⌘+Shift+Enter` — Run with
  AI, `Ctrl/⌘+S` — сохранить.

## Локальный запуск

Playground — статические файлы. Нужен HTTP-сервер (не `file://`):

```bash
cd web-ide
python3 -m http.server 8000
# http://localhost:8000
```

Или через собранный сайт документации: `docs/static/playground/` — это копия
`web-ide/`, которую при сборке делает `scripts/sync-playground.mjs`.

## Ограничения

- Движок №2 — подмножество языка; host-фичи дают явную ошибку. Полный список
  отличий — в разделе
  [«Ограничения движка №2»](../guide/wasm-and-execution.md#ограничения-движка-2).
- В движке №2 `print` выводит каждый аргумент с новой строки (host-функция
  `env.print` вызывается на каждый аргумент), а в движке №1 — одной строкой
  через пробел.
- Форматирование не является AST-принтером: это нормализация отступов и
  пробелов.
- AI-режим работает через AI-гейтвей; без настроенного провайдера включается
  mock-режим.
