# Лямбды и замыкания

## Две формы

```text
fn (параметры) => выражение        // короткая
fn (параметры) { инструкции }      // блочная
```

```latent
fn main() -> int {
    let double = fn(x) => x * 2;
    let scale = fn(x) {
        let y = x + 1;
        return y * 10;
    };
    print(double(21));
    print(scale(4));
    return double(21);
}
```

- параметры могут иметь аннотации; без аннотации — `i32`;
- аннотация типа возврата у лямбды парсится, но кодогенератором
  **игнорируется**;
- лямбда — значение: присваивается, передаётся в вызов, возвращается.

## Функции высшего порядка

```latent
fn apply(f, x) {
    return f(x);
}

fn apply_twice(f, x) {
    return f(f(x));
}

fn main() -> int {
    let inc = fn(x) => x + 1;
    print(apply(inc, 10));
    print(apply_twice(inc, 10));
    return apply_twice(inc, 10);
}
```

Именованную функцию нельзя передать как значение — оборачивайте в лямбду:

```latent
fn square(x: int) -> int {
    return x * x;
}

fn apply(f, x) {
    return f(x);
}

fn main() -> int {
    return apply(fn(v) => square(v), 7);
}
```

`let f = square;` в движке №2 — ошибка `Undefined variable: square`.

## Замыкания

Лямбда захватывает свободные переменные окружающей функции:

```latent
fn main() -> int {
    let base = 100;
    let add_base = fn(x) => x + base;

    let factor = 3;
    let triple = fn(x) {
        return x * factor;
    };

    print(add_base(5));
    print(triple(7));
    return add_base(5);
}
```

Как это устроено в движке №2:

- лямбда компилируется в отдельную функцию с неявным первым параметром —
  указателем на окружение;
- значение лямбды — 8 байт: `[индекс функции в таблице][env-указатель]`;
- вызов — `call_indirect` по индексу из таблицы элементов;
- захватываются только `i32`/указатели; захват `float` даёт невалидный WASM.

## Рекурсия через лямбду невозможна

Лямбда не знает своего имени. Для рекурсии используйте именованную функцию
(см. [функции](./functions.md)).

## Ограничения движка №2

- Захваты — только `i32`; float-захват невалиден.
- Аннотация возврата лямбды игнорируется.
- Именованные функции не являются значениями первого класса.
- Арность лямбды проверяется: вызов с другим числом аргументов —
  `Несовпадение арности`.
- Если лямбда передаётся в нетипизированный параметр, её сигнатура в
  `call_indirect` — `i32`-based; для функций с `float`/`f64`-сигнатурой
  косвенный вызов может не сойтись по типу.

## Отличия движка №1

JS-интерпретатор поддерживает лямбды и замыкания без float-ограничений и без
`call_indirect`-деталей — там это обычные JS-функции.
