# Руководство по языку

Этот раздел — систематическое описание языка Latent: от лексики до ABI WASM.
Туториал отвечает на вопрос «как написать программу», руководство — «как язык
устроен и что именно он гарантирует».

## Обозначения

- Блоки с примерами помечены `latent` и **проверяются компилятором** при
  сборке документации.
- Пример, который заведомо не компилируется движком №2, помечен комментарием
  `// Не компилируется движком №2: ...` или `// ошибка`.
- В конце каждой темы есть раздел **«Ограничения движка №2»**: что именно из
  описанного не работает в Rust → WASM-компиляторе.
- Различия двух движков собраны в
  [wasm-and-execution](./wasm-and-execution.md#различия-движков).

## Два движка в одном абзаце

- **Движок №1** — JS-интерпретатор в web IDE: исполняет программы, включая
  каналы, AI и тензоры, поддерживает `enum` и файловые модули; не знает битовых
  операторов и блочных комментариев.
- **Движок №2** — Rust-компилятор в WASM: компилирует подмножество в
  WASM-модуль; для host-фич даёт явную ошибку
  `Builtin '...' не поддерживается движком №2 (требует host-рантайма)`.

Программа может состоять из нескольких `.lat`-файлов: файловые модули
(`import`/`export`) линкуются на этапе компиляции — см. [модули](./modules.md).
Пакетного менеджера и внешних зависимостей по-прежнему нет.
