# Функции

## Объявление

```text
'fn' (IDENT | keyword) '(' Params? ')' ('->' Type)? '{' Block '}'
Params := IDENT (':' Type)? (',' IDENT (':' Type)?)*
```

```latent
fn add(a: int, b: int) -> int {
    return a + b;
}

fn main() -> int {
    print(add(2, 3));
    return add(2, 3);
}
```

- именами функций могут быть и «мягкие» ключевые слова (`fn model() {}`) и
  даже `new`/`ai`;
- аннотации параметров необязательны; без аннотации параметр — `i32`;
- `-> Тип` необязателен.

## Вывод типа результата

- есть `-> T` — сигнатура берёт `T`;
- без аннотации, но в теле есть `return выражение;` — результат `i32`
  (поэтому для `float` аннотация обязательна);
- без аннотации и без `return` — функция void.

Если объявлен результат, а тело не заканчивается `return`, кодоген добавляет
заглушку (`i32.const 0`/`f64.const 0`), поэтому:

```latent
fn first_positive(n: int) -> int {
    if (n > 0) {
        return n;
    }
    // сюда можно не писать return 0 — кодоген подставит 0
}

fn main() -> int {
    print(first_positive(5));
    print(first_positive(-5));
    return 0;
}
```

## Хойстинг и рекурсия

Сигнатуры всех функций регистрируются до тел, поэтому порядок объявления не
важен, а рекурсия и взаимная рекурсия работают:

```latent
fn is_even(n: int) -> bool {
    if (n == 0) {
        return true;
    }
    return is_odd(n - 1);
}

fn is_odd(n: int) -> bool {
    if (n == 0) {
        return false;
    }
    return is_even(n - 1);
}

fn main() -> int {
    if (is_even(10)) {
        print("even");
    }
    return 0;
}
```

## `main` и код возврата

```latent
fn main() -> int {
    print("done");
    return 0;
}
```

- `main` экспортируется из WASM-модуля, если объявлена;
- `-> int` — стандартный вид; `-> float` синтаксически допустим;
- `fn main() { ... }` (без аннотации) экспортируется как void-функция;
- если `main` нет, модуль валиден, но экспортирована только `memory`.

## `async` / `await`

```latent
async fn fetch_value() -> int {
    return 42;
}

fn main() -> int {
    let v = await fetch_value();
    print("awaited:", v);
    return v;
}
```

- typechecker требует, чтобы `await` применялся к `Promise<T>`, а `async fn`
  возвращает `Promise<T>`; `await` обычной функции — ошибка типов;
- в движке №1 `async fn` возвращает промис, `await` его разворачивает;
- в движке №2 `async fn` — обычная функция, `await` — прозрачное разворачивание
  значения (Promise в рантайме нет).

## Чего нет

- перегрузки функций: дубликат `fn f` не диагностируется, вторая сигнатура
  перезаписывает первую;
- вложенных `fn` в блоках: они парсятся, но не регистрируются —
  `Unknown function: inner`;
- функций как значений напрямую: `let f = square;` в движке №2 — ошибка
  `Undefined variable: square`; оборачивайте в лямбду `fn(x) => square(x)`;
- аргументов по умолчанию, variadic-функций, named-аргументов;
- `return` без значения в функции с `-> T` — ошибка типов; в функции с
  `-> void`/`-> unit` — невалидный WASM.

## Встроенные функции

Builtins обрабатываются по имени и имеют приоритет над пользовательскими
функциями с тем же именем (переопределить `len`, `print` и т.п. нельзя).

| Функция | Смысл |
|---|---|
| `print(a, ...)` | печать; в движке №2 каждый аргумент — отдельной строкой |
| `len(x)` | длина массива/строки |
| `push(arr, v)` | добавить в массив; возвращает массив |
| `str(x)`, `int(x)`, `float(x)`, `sqrt(x)` | преобразования |
| `assert(cond)`, `assert_eq(a, b)` | проверки |
| `alloc`, `load8`, `store8`, `load32`, `store32`, `memcopy` | линейная память |
| `channel`, `tensor`, `ai_infer`, … | host-фичи (движок №1) |

Полные сигнатуры и ограничения — в
[массивах и строках](./arrays-and-strings.md) и
[WASM](./wasm-and-execution.md).

## Ограничения движка №2

- `fn f() -> unit { return; }` и `fn f() -> void { return; }` — невалидный WASM;
  не аннотируйте void-функции.
- Безымянный возврат `float` без аннотации превращается в `i32`.
- Вложенные и декорированные функции не регистрируются.
- `async`/`await` — суррогат без реальных Promise.
- Ошибки вызова: `Несовпадение арности ...` — от typechecker'а,
  `Unknown function: name` — от кодогена.
