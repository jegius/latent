# Синтаксис и лексика

## Файл и структура программы

Программа Latent — один файл `.lat`. Модулей, импортов и пространств имён нет.
Верхний уровень содержит объявления:

- `fn` / `async fn` — функции;
- `class` — классы;
- `enum` — sum-типы;
- `let` — глобальные переменные (типизируются, но **не исполняются** движком
  №2: код для верхнеуровневых инструкций не эмитится);
- `test "имя" { ... }` — тесты;
- `@декоратор` над объявлением.

Точка входа — `fn main() -> int`; её наличие экспортирует `main` из
WASM-модуля. Программа без `main` скомпилируется, но запустить её нечем.

## Документационный пример

```latent
// Комментарий до объявлений.
fn main() -> int {
    let x = 1; // инструкция обязана завершаться ';'
    /* блочный комментарий
       /* поддерживает вложенность */ */
    print("x =", x /* комментарий внутри выражения */);
    return x;
}
```

## Литералы

| Литерал | Пример | Детали |
|---|---|---|
| число | `42`, `3.14`, `1e10`, `1.5e-3` | лексема — всегда `f64`; дробная часть — только если после `.` идёт цифра; экспонента `e/E` обязана иметь цифры |
| строка | `"text"` | только двойные кавычки; escapes: `\n`, `\t`, `\\`, `\"` |
| boolean | `true`, `false` | ключевые слова |
| null | `null` | ключевое слово; представляется как `0` |

Ограничений много, и они важны для переносимости:

- **нет** шестнадцатеричных/двоичных литералов, разделителей `_`, суффиксов
  (`1i64`), `Infinity`/`NaN`;
- `1.` — не число: точка не потребляется, если за ней не цифра;
- `0x10` разберётся как `0` и идентификатор `x10` → ошибка парсинга;
- любая другая escape-последовательность (`\r`, `\0`, `\u{...}`) — ошибка
  `Неверная escape-последовательность`;
- целые > 2^53 теряют точность (лексема `f64`), а в кодеген уходят как `i32`
  и могут переполниться.

## Идентификаторы

```text
identifier := [A-Za-z_][A-Za-z0-9_]*
```

Только ASCII, регистрозависимы. `let имя = 1;` — ошибка
`Неожиданный символ 'и'`.

## Ключевые слова

**Жёсткие** (нельзя использовать как имена):

```text
let fn if else while for in return class new this async await spawn channel
select case default yield match enum true false null
ai model agent embedding tensor semantic
test assert assert_eq forall snapshot ai_contract enforce_contract
```

**Мягкие** — лексер помечает их особым токеном, но синтаксически они допустимы
как имена (`let test = 5;`, `fn model() {}`, `obj.agent`):

```text
test assert assert_eq forall snapshot ai_contract enforce_contract
model agent embedding tensor semantic case
```

`print` — **не** ключевое слово: это обычный идентификатор, обрабатываемый
кодогенератором как builtin.

```latent
fn model() -> int {
    let test = 5;
    return test;
}

fn main() -> int {
    return model();
}
```

## Комментарии

```latent
// до конца строки
/* блочный; /* вложенный */ всё ещё комментарий */
```

Незакрытый `/*` — ошибка `Незавершённый блочный комментарий на строке L:C`.
Блочные комментарии не поддерживаются JS-движком №1.

## Точки с запятой

Автоматической вставки `;` нет, пустой инструкции `;` нет.

| Конструкция | `;` |
|---|---|
| `let x = e;` | обязательна |
| `return e;` / `return;` | обязательна |
| `yield;` | обязательна |
| `match ... { ... };` как инструкция | обязательна |
| выражение-инструкция `e;` | обязательна |
| `spawn { ... }` / `spawn f();` | необязательна |
| `select { ... }` | необязательна |
| `if`/`while`/`for`, `fn`/`class`/`enum` | не нужна |
| поле класса `x: int;` | обязательна |

`;` после блока (`if (...) { } ;`) — ошибка.

## Скобки и вызовы

- `if`/`while`/`for` требуют круглых скобок; `match`/`select` — без скобок;
- блоки — только `{ ... }`; одиночная инструкция вместо блока не допускается;
- `new` требует скобок: `new Point(3, 4)`; `new Point` без вызова — это
  идентификатор `"new Point"` и ошибка;
- литерал массива допускает завершающую запятую: `[1, 2, 3,]`;
- вызов допускает завершающую запятую: `f(a, b,)`.

## Ограничения движка №2

- Верхнеуровневые `let`/выражения не эмитятся (но типизируются).
- Вложенные `fn` парсятся, но не регистрируются → `Unknown function`.
- `;`-правила одинаковы для обоих движков; JS-движок мягче не делает.
