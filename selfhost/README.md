# Self-hosted компилятор Latent

`shc.lat` — компилятор Latent→WASM, написанный на самом Latent (подмножество языка),
без опоры на Rust-реализацию. Цель — bootstrap (фиксированная точка): компилятор,
собранный собой, побайтово совпадает с собой.

## Что уже поддерживается подмножеством

* объявления `fn`, параметры, `return`;
* `let` (с аннотацией типа и без), присваивание `x = ...` (в т.ч. как выражение);
* `if` / `else` / `else if`, `while`, C-стиль `for (init; cond; step)`;
* целочисленные выражения `+ - * / %`, сравнения `== != < > <= >=`,
  логические `&& ||` (не короткозамкнутые), битовые `& | ^ << >>`, унарные `- !`,
  литералы `true`/`false`, числовые и строковые литералы;
* вызовы функций, встроенные функции памяти `alloc`, `load8`, `load32`,
  `store8`, `store32`, `memcopy`, а также `print`;
* массивы-как-указатели: `arr[i]` = 4-байтовое чтение/запись по `base + i*4`
  (байтовый доступ — через `load8`/`store8`).

## ABI компилятора

| Адрес  | Назначение                                                     |
|--------|----------------------------------------------------------------|
| 32768  | входной исходник: `[len u32 LE][utf8 bytes]`                   |
| 65536  | выходной WASM: `[len u32 LE][bytes]` после вызова `main()`      |

`main()` компилятора возвращает длину выходного WASM.

## Запуск

```sh
cargo build --bin latentc
node selfhost/bootstrap.mjs
```

`bootstrap.mjs` выполняет цепочку:

1. `latentc` (Rust) собирает `selfhost/shc.lat` → `stage1.wasm`;
2. `stage1.wasm` компилирует `selfhost/shc.lat` → `stage2.wasm` (self-compiled);
3. `stage2.wasm` компилирует `selfhost/shc.lat` → `stage3.wasm`;
4. проверяется `stage2 == stage3` (фиксированная точка).

## Статус

* **Достигнуто.** `shc.lat` корректно компилирует широкое подмножество языка;
  `latentc` собирает `shc.lat`; компилятор, запущенный, производит валидный
  WASM для типовых программ (рекурсия, циклы, строки, работа с памятью).
* **Почти достигнуто.** `stage2.wasm` — результат самокомпиляции — получается,
  но на полном размере `shc.lat` в одном из крупных методов кодогенератора
  возникает невалидный участок (движок отклоняет модуль). Остаётся довести
  эмиссию тел крупных функций до полной корректности, после чего цепочка
  замкнётся в фиксированную точку.

## Побочный результат: примитивы памяти

Для селф-хостинга в Rust-реализацию (`latentc`) добавлены встроенные
небезопасные примитивы линейной памяти: `alloc(size)`, `load8(addr)`,
`store8(addr,v)`, `load32(addr)`, `store32(addr,v)`, `memcopy(dst,src,len)`.
Без них компилятор на Latent не мог бы формировать байты WASM. См.
`src/codegen/emit_call.rs` (`compile_memory_builtin`).
